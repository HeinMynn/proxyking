—
  1. Configure the Wi-Fi HTTP proxy using the address shown by the setup page.
  2. Install Proxyking Local CA. On iOS, also enable it under General → About → Certificate Trust Settings; profile installation alone does not enable SSL trust.

The setup page and CA stay on your local network. Mobile operating systems require manual confirmation before changing proxy or certificate trust settings.
